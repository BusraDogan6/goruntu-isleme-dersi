# OpenCV CUDA Kurulumu

Bu çalışmada Google Colab üzerinde CUDA destekli OpenCV kurulumu gerçekleştirilmiştir.

## Kullanılan Ortam

- Google Colab
- C++
- OpenCV 4.14.0
- CUDA 12.8
- NVIDIA Tesla T4

## Kontrol

Kurulum sonrasında C++ kullanılarak CUDA destekli GPU erişimi test edilmiştir.

Test sonucunda:

- OpenCV Version: 4.14.0
- CUDA GPU Sayısı: 1
- GPU: Tesla T4

bilgileri alınmıştır.

## Sonuç

OpenCV, CUDA desteği ile başarılı şekilde kurulmuş ve C++ tarafından GPU erişimi doğrulanmıştır.
